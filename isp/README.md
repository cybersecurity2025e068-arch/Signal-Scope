# لوحة إدارة مشتركي الإنترنت

لوحة ويب عربية لإدارة شبكة إنترنت محلية: المشتركون، الباقات، الوكلاء وأرصدتهم، كروت التعبئة، التقارير، وربط اختياري مع FreeRADIUS لتفعيل وإيقاف حسابات PPPoE فعلياً على MikroTik.

- PHP 7.4+ بلا إطار عمل ولا Composer، وقاعدة MySQL / MariaDB.
- تعمل على استضافة cPanel عادية، والنشر من Git Version Control.
- واجهة RTL تعمل على الحاسوب والهاتف، مع وضع ليلي تلقائي.

## الأقسام

| القسم | ماذا يفعل |
|---|---|
| الرئيسية | أعداد المشتركين حسب الحالة، تفعيلات اليوم والشهر، مخطط 14 يوماً، من ينتهي قريباً |
| المشتركون | بحث وفلترة (الحالة، الباقة، الوكيل، المنطقة)، تصدير Excel، إضافة وتعديل |
| صفحة المشترك | تفعيل/تجديد بالرصيد أو بكارت، إيقاف/تشغيل، تمديد مجاني، تعيين تاريخ الانتهاء، نقل لوكيل، إلغاء آخر تفعيل مع إرجاع المبلغ أو الكارت، إيصال للطباعة، الجلسات والاستهلاك (مع RADIUS)، سجل العمليات |
| الباقات | السرعة، المدة، سعر الوكيل، سعر البيع، حجم البيانات، مجموعة RADIUS |
| الوكلاء والمستخدمون | ثلاثة أنواع: مدير، موظف، وكيل. للوكيل رصيد وحد ائتمان، والإيداع والسحب والتسوية مسجّلة |
| الكروت | توليد دفعات (حتى 2000 كارت)، طباعة الكروت، تصدير، فحص كارت، تعطيل كارت |
| الحركات المالية | كشف حساب لكل وكيل مع الرصيد بعد كل حركة، وتصدير Excel |
| التقارير | المبيعات حسب اليوم أو الشهر أو الباقة أو الوكيل أو طريقة الدفع، والمشتركون الجدد والمنتهون |
| المتصلون الآن | الجلسات الحالية من جدول radacct (عند تفعيل RADIUS) |
| سجل العمليات | من فعل ماذا ومتى ومن أي IP |
| بوابة المشترك | يدخل المشترك باسم وكلمة مرور PPPoE، يرى تاريخ انتهاء اشتراكه ويشحن بكارت بنفسه |

### الصلاحيات
- **المدير**: كل شيء، بما فيه الباقات والأرصدة والإعدادات.
- **الموظف**: يدير كل المشتركين ويرى التقارير، ولا يعدّل الباقات أو الأرصدة.
- **الوكيل**: يرى مشتركيه فقط. كل تفعيل يُخصم من رصيده، ويشتري الكروت من رصيده.

### قواعد الحساب
- التجديد والاشتراك ما زال سارياً يضيف المدة إلى تاريخ الانتهاء الحالي، لا إلى اليوم.
- الخصم لا يتجاوز الرصيد + حد الائتمان. كل خصم يتم داخل معاملة قاعدة بيانات واحدة مع قفل صف الوكيل.
- إلغاء آخر تفعيل يعيد التاريخ والباقة السابقين، ويرجع المبلغ للوكيل أو يعيد الكارت جديداً.

## النشر على cPanel

1. في cPanel افتح **Git™ Version Control** ← **Create**، وألصق رابط هذا المستودع.
2. **Manage** ← **Pull or Deploy** ← **Update from Remote** ثم **Deploy HEAD Commit**.
3. أول Deploy يُنشئ تلقائياً:
   - قاعدة `<user>_isp` ومستخدماً بكلمة مرور عشوائية، و `~/isppanel/config.php`
   - الجداول وثلاث باقات مثال وحساب المدير
   - مهمة cron يومية
4. بيانات الدخول في `~/isppanel/SETUP-INFO.txt` (افتحه من File Manager، ثم احذفه).
5. اللوحة على `https://نطاقك/isp/` وبوابة المشترك على `https://نطاقك/isp/index.php?p=portal`.

سجل الإعداد في `~/isppanel/install.log`. ملفات المنطق والإعدادات خارج `public_html`.

نسيت كلمة مرور المدير؟ من Terminal في cPanel:
```bash
php ~/isppanel/bin/reset-admin.php admin
```

## الربط مع FreeRADIUS و MikroTik (اختياري)

اللوحة تكتب حالة كل مشترك في جداول FreeRADIUS (`radcheck` و `radreply` و `radusergroup`) فور أي تغيير:

| الصفة | المصدر |
|---|---|
| `Cleartext-Password` | كلمة مرور المشترك |
| `Expiration` | تاريخ الانتهاء؛ FreeRADIUS يرفض الدخول بعده تلقائياً |
| `Auth-Type := Reject` | عند الإيقاف أو قبل أول تفعيل |
| `Simultaneous-Use` | عدد الجلسات المسموح بها |
| `Mikrotik-Rate-Limit` | السرعة من الباقة، بصيغة رفع/تنزيل مثل `5M/25M` |
| `Framed-IP-Address` | العنوان الثابت إن وُجد |
| `Calling-Station-Id` | عنوان MAC، فقط إن فعّلت `bind_mac` |

للتفعيل عدّل `~/isppanel/config.php`:
```php
'radius' => [
    'enabled' => true,
    'dsn'  => 'mysql:host=IP_خادم_RADIUS;dbname=radius;charset=utf8mb4', // فارغ = نفس قاعدة اللوحة
    'user' => 'radius_user',
    'pass' => '...',
    'rate_attr' => 'Mikrotik-Rate-Limit',
    'simultaneous_use' => 1,
    'bind_mac' => false,
],
```

ملاحظات:
- خادم FreeRADIUS يكون عادة في مقر الشبكة. إن كانت قاعدته على جهاز آخر، يجب أن يسمح MySQL هناك باتصال الاستضافة (Remote MySQL)، أو اجعل FreeRADIUS يقرأ من قاعدة الاستضافة نفسها.
- تفعيل وحدة `expiration` في FreeRADIUS ضروري لاحترام `Expiration`.
- تغيير الحالة لا يقطع جلسة متصلة الآن. التطبيق يحدث عند الاتصال التالي، أو اقطعها من MikroTik.
- لا تحتاج cron لانتهاء الاشتراكات: `Expiration` يتكفّل بذلك. المهمة اليومية تعيد المزامنة احتياطاً فقط.

## التطوير المحلي

```bash
cp app/config.example.php app/config.php   # عدّل بيانات القاعدة
php app/bin/install.php                     # يطبع كلمة مرور المدير
php -S 127.0.0.1:8080 -t public
```

## الأمان
- كلمات مرور المستخدمين مخزّنة بـ `password_hash`، والجلسات `HttpOnly` و `SameSite`.
- رمز CSRF على كل نموذج، واستعلامات مُعدّة (prepared) فقط.
- حدّ لمحاولات الدخول الفاشلة لكل IP (8 خلال 15 دقيقة) في اللوحة والبوابة.
- تغيير كلمة المرور يُخرج الجلسات الأخرى.
- كلمات مرور PPPoE للمشتركين محفوظة كنص لأن RADIUS يحتاجها كذلك. لا تشارك نسخ القاعدة الاحتياطية.
